# EXP-2026-09-28-s2b-wait — Famille L (WAIT) : t0 est-il optimal ?

- **hypothesis_id** : H-S2B-L1
- **question** : Ne pas supposer que t0 est optimal. Existe-t-il un délai d'attente Δ après t0 tel que INFORMATION_GAIN(Δ) > ENTRY_DELAY_COST(Δ) ?
- **method** :
  1. Δ secondes littéraux {30s, 60s, 120s} : couverture (≥1 tick valide dans (t0, t0+Δ]).
  2. Δ minutes {15, 30, 60, 120} (cadence supportée par les données) : features d'attente sur ticks de timestamp ≤ t0+Δ uniquement — `dirPrice` = log(p_dernier≤D / p_t0), `dLiq` = log(liq_dernier≤D / liq_t0).
  3. INFORMATION_GAIN : Spearman(dirPrice → Y@1h/Y@6h **depuis l'entrée**, pas de chevauchement feature/label) + p de permutation ; spread top−bottom tercile de dirPrice sur Y@1h depuis l'entrée (unités de rendement) + p de permutation ; taux d'événement survie_50 par tercile de dirPrice.
  4. ENTRY_DELAY_COST(Δ) = ret(t0→t0+H) − ret(entrée→entrée+H), H ∈ {1h, 6h}, médiane/moyenne/IC95% bootstrap. Entrée = premier tick valide ≥ t0+Δ (prix réellement payé).
  5. Robustesse : winsorisation |Y|≤10, cohortes dex (pumpswap/reste), moitiés temporelles (split 2026-09-26), adversarial « survie vs référence t0 fixe ».
- **data** : `data/history/*.jsonl` (2926 séries), lecture seule ; discovery uniquement (503 tokens avec t0) ; SKHY exclu. **Biais déclaré : tokens chauds → borne OPTIMISTE.**
- **n** : Δ=15min : 308 en fenêtre, 165 Y@1h, 217 survie ; Δ=30min : 439/227/274 ; Δ=60min : 461/210/234 ; Δ=120min : 471/197/198.
- **leakage_status** : **PASS** — features sur ticks ≤ t0+Δ ; labels mesurés depuis l'entrée (premier tick ≥ t0+Δ) ; ticks aberrants masqués ; AUCUNE lecture du holdout. (Le prix d'entrée peut être observé après t0+Δ — données clairsemées — utilisé uniquement pour le coût réalisé, documenté.)
- **results** :
  - **Δ secondes : couverture 0/503 à 30s, 60s et 120s.** Cadence collecteur ~1 tick/14 min (médiane) : aucune information observable en attendant quelques secondes → **DATA_ISSUE** pour l'hypothèse littérale.
  - **ENTRY_DELAY_COST** (médiane, H=1h) : Δ=15min +0,0047 · Δ=30min +0,0065 · Δ=60min −0,0000 · Δ=120min −0,0044. **Attendre ne coûte essentiellement rien à la médiane.** Moyenne +0,17/+0,33 (IC95% excluant 0 à 1h) : tirée par des outliers (tokens qui pumperaient juste après t0 et qu'on rate en attendant).
  - **INFORMATION_GAIN dirPrice→Y@1h** : Δ=15min ρ=−0,074 (p=0,34) · Δ=30min ρ=−0,014 (p=0,83) · Δ=60min ρ=+0,116 (p=0,09) · **Δ=120min ρ=+0,256 (p=0,0002, pPerm=0,0005)**. dLiq cohérent (Δ=120min ρ=+0,241, p=0,0005) ; Y@6h Δ=120min ρ=+0,231 (p=0,004).
  - MAIS spread tercile Y@1h jamais significatif (pPerm 0,28–0,97) : la structure en déciles (Δ=120min) montre D1–D5 négatifs (−0,03/−0,08), D6–D9 positifs monotones (0,00→+0,10), **D10 (pumps ~+200 %) en reversal brutal : moyenne −0,256, médiane −0,147** — le « don't chase the vertical » (cohérent H-PRED-FLOW-01, twist H-CHASE).
  - Stabilité temporelle du momentum Δ=120min : early (n=71) ρ=+0,067 (nul), late (n=126) ρ=+0,350 → **UNSTABLE** ; la pente D1–D9 disparaît dans les moitiés (effet de composition) ; seul le **reversal D10 est présent dans les deux moitiés** (early −0,43, late −0,11) mais n=20.
  - **Signal survie TUÉ par l'adversarial** : up-move pendant l'attente → +20/+31 pts de taux d'événement −50 % depuis l'entrée (Δ=15min : 0,61→0,89, pPerm=0,0005 ; Δ=30min : 0,54→0,85 ; Δ=60min : 0,53→0,76). MAIS mesuré vs **référence t0 fixe**, l'écart disparaît (Δ=15min : 0,797→0,767 ; Δ=30min : 0,763→0,741) → **pur effet mécanique du prix d'entrée gonflé**, aucune information sur la trajectoire future au-delà du niveau. Vrai comme arithmétique du risque réalisé, faux comme signal prédictif.
- **verdict** : **NEAR_MISS** — pas de Δ avec INFORMATION_GAIN robuste et stable > ENTRY_DELAY_COST (≈ 0 à la médiane). Piste fragile mais cohérente : le reversal des pumps extrêmes (D10, « don't chase the vertical ») comme RISK FILTER, à confirmer (n=20, holdout). Le signal survie est KILLED (mécanique) ; le momentum 120min est UNSTABLE (temps).
- **second-order** : dLiq bouge avec dirPrice (cohérent) ; le coût moyen > médian pointe les outliers manqués — même asymétrie que H-EXIT (moyenne fabriquée par les extrêmes).
- **contrefactuel** : permutations → les spreads Y@1h sont indistinguables du bruit sauf la structure D10 ; la survie vs t0 est indistinguable du bruit → INCONCLUSIVE→KILLED.
